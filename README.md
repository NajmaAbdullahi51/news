# 📰 Dynamic News Portal System (Laravel)

A modern, content-driven web application built with Laravel designed for publishing, managing, and browsing news articles and categories seamlessly.

## 🛠️ Tech Stack & Tools
* **Backend:** PHP (Laravel Framework)
* **Database:** MySQL
* **Frontend:** Blade Templates, HTML5, CSS3, & Tailwind / Bootstrap
* **Environment:** Local Development Server (XAMPP / VS Code)

## 🚀 Key Features
* **Article Management:** Create, edit, publish, and delete news articles with rich titles, categories, and content.
* **Category Organization:** Categorize news (such as Technology, World, Local, Sports) for easy user navigation.
* **Dynamic Frontend:** Clean and responsive layout displaying breaking news, trending stories, and latest updates.
* **Database Integration:** Secure storage and lightning-fast retrieval of articles and user comments using Laravel Eloquent ORM and MySQL.
